# Grievance Redressal Standard Operating Procedure (DPDP Act, Section 8(10))

## 1. Overview
Section 8(10) of the DPDP Act mandates that every Data Fiduciary establish an easily accessible grievance redressal mechanism.

## 2. In-App Workflow
1. **Submission:** User navigates to Privacy Center -> Grievance Redressal.
2. **Category Selection:**
   - Inaccurate data correction failure (S12)
   - Erasure request non-fulfillment (S12)
   - Unwanted marketing communications (S6)
   - Minor data processing concern (S9)
   - Security safeguard inquiry (S8(5))
3. **Ticket Generation:** System generates unique ticket format `GRV-[YEAR]-[UUID]`.
4. **Acknowledgement:** Automated SMS/email sent immediately with tracking link.
5. **SLA Window:** 72 business hours for formal investigation and written decision.
6. **Escalation Path:** If the user is dissatisfied or 72 hours elapse without resolution, the screen renders an escalation button linking directly to the Data Protection Board of India complaint portal.
